## 来源判断

PDF 标题将内容归为 Simon 范文，抽查文本也与网络上流传的 Simon Task 2 材料一致。但是：

- PDF 没有原始文章 URL、发布日期或逐篇出处；
- PDF 元数据中的作者是 `sshh`，不是 Simon；
- 18 篇末尾标有 `band 9`，10 篇没有 band 标签；
- 全集没有 IELTS 考官评语，`band 9` 只能视为合集标注，不能作为官方评分；
- 文本层存在少量由 PDF 排版产生的词内空格，入库时须逐页对照视觉文本清理并记录。

因此正式来源类型为 `teacher_model`，作者显示为“Simon（合集归属，一手来源待核验）”，可靠性不能等同于 IELTS 官方考生答卷或 Cambridge examiner-written model answer。
