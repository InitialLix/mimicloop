# Guided Writing Essay Closure v1

## 目标

把同一道题里已经通过的 learner-owned Introduction、Body Paragraph 1、Body Paragraph 2 继续收束为 learner-owned Conclusion，并形成可展示、可恢复、可追溯的四段文章闭环。

## Conclusion

- 前置：两段正文 Logic / Language 均 clear，最新 Introduction 的 Task Response / Language 均 clear。
- 输入：learner 自写结论，不固定句数。
- 检查：是否回应并收束题目、是否与 Position 和两段正文一致、是否突然加入新主论点、语言是否清楚自然。
- 输出：Task Response 与 Language 两栏观察；不提供范文、替换句或 Band 分数。
- 保存：append-only 保存 learner 原文；模型不可用时仍保留并可重试。

## Full essay

- 只拼接四段已经保存并通过的原文，不自动润色或改写。
- 最终检查分为 Task Response、Coherence、Language，每栏最多一个当前最值得处理的问题。
- 用户修改时回到对应段落，不在全文页接受“整篇一键改写”。
- 使用过的语料仅从两个主体段正式节点尝试中回算；显示具体资产、使用节点、hint level 与 learned/new，不把用过视为掌握。

## 展示闭环

```text
归档 IELTS 题目
→ learner 论证链
→ approved 语料逐节点激活
→ learner 自写两个主体段
→ learner 自写开头与结论
→ 四段原文组装
→ Task / Coherence / Language 终检
→ 回看本次真实语料迁移与下一学习入口
```

该流程可以说明产品依据 IELTS 官方公开评价目标设计，但不得描述为 IELTS 官方认证、官方评分或固定教学法。
