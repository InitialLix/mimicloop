# ADR 0009：仿写自然度优先于结构忠实度

- 状态：Accepted
- 日期：2026-08-18

## 背景

现有仿写流程强调从原句抽取 pattern 和 slots。实际使用发现，若只验证语法、slot 对应和目标表达是否出现，机械更换主题或名词仍可能产生语法正确但不够自然的现代英语，甚至带有老派语感、异常搭配、翻译腔或套模板感。

这类句子不适合作为主动输出范例。学习者可能记住一个形式，却同时学习到母语者不会优先采用的表达。

## 决策

所有 Sentence Use、Collocation Use、`transfer_example` 和替换示例都采用以下审核优先级：

1. 现代英语自然度和地道度；
2. 语义逻辑准确；
3. IELTS / 正式写作适用性；
4. 原句结构保留程度。

每条生成句必须接受一次脱离原句的 blind native-naturalness check。审核者假设看不到来源，只判断新句本身是否像受教育英语母语者自然写出的现代正式表达。语法正确但不够自然仍判失败。

原结构不适合新语境时允许：

- 只保留其中真正可迁移的局部；
- 更换仿写主题；
- 使用更简单、更常见的表达；
- 放弃该仿写句并将候选退回 `needs_edit`。

## 结果

- slot 与 pattern 只提供生成方向，不构成质量证明；
- 当自然参考答案偏离来源 pattern 时，Use 保存并展示独立 `feedback_pattern`，不再用旧骨架冒充本题结构；
- 确定性校验继续检查字段、来源、提示、目标表达和重复，但不得声称能够自动证明母语自然度；
- 人工审核必须明确检查搭配对象、单复数、可数性、介词、动词宾语、语体和模板感；
- 现有全部正式迁移句需要建立一次自然度审计基线，之后新增内容按相同门禁处理。
