# ADR 0005：MimicLoop 品牌与 IELTS 定位标识

- 状态：Accepted
- 日期：2026-08-16

## 背景

首页需要更清楚地体现产品服务于 IELTS Academic Writing Task 2，用户也提供了完整的 MimicLoop 软件 Logo，并希望在多个页面形成统一品牌识别。

IELTS 官方声明将 `IELTS`、`雅思`及其 Logo 列为受保护商标，并要求使用商标时联系相关 IELTS Partner 获取许可。个人、非商用用途不自动构成 Logo 使用许可。

## 决策

1. 使用用户提供的透明 PNG 作为 MimicLoop 主品牌资产；首页展示完整 Logo，全局侧栏展示同一资产的机器人标志。
2. 首页标题直接写明“雅思范文”，顶部以普通文字标识 `IELTS Academic · Writing Task 2`。
3. 未获得书面许可前不复制、仿制或展示 IELTS 官方 Logo。
4. 首页明确注明 MimicLoop 是独立学习工具，与 IELTS 官方无隶属或合作关系。

## 后果

- 所有主要页面通过全局侧栏获得一致的 MimicLoop 品牌识别；
- 用户可以立即看出产品的 IELTS 写作定位；
- 页面不会形成官方合作、授权或评分背书的误解。
