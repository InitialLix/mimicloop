# ADR 0002：首批 Simon 来源与弹性筛句

- 状态：Superseded by ADR 0003
- 日期：2026-08-16

## 背景

原始规格建议首个内容包混合 Simon、Cambridge、IELTS 官方和 IELTS Liz，并用每篇约 4–6 张卡估算规模。用户确认第一批范文正文希望全部来自 Simon，同时不希望按固定句数机械筛选。

## 决策

1. 开发种子与首个可用内容包的范文正文全部来自 IELTS Simon。
2. Cambridge / IELTS 官方内容只用于题目、写作要求和评分标准校准，不作为第一批范文正文。
3. 每篇范文不设固定卡片数量。AI/Codex 适度扩大候选范围，最终由学习价值和人工审核决定收录数量。
4. 至少 15 张经审核的正式卡仍是 MVP 的内容验收门槛，但它是整体最低门槛，不是单篇配额。

## 筛选门槛

候选句必须至少具备一项明确价值：自然且值得掌握的词块、可复用结构、明确论证功能或可设计的 Recall/Use 练习。同时必须排除高度重复、强依赖上下文、搭配可疑和仅因冗长而显得“高级”的句子。

## 后果

- 内容包卡片总数是结果，不是生产指标；
- 一篇高密度文章可以形成较多卡片，但学习调度应分散投放；
- 所有 Simon 句子仍须保存原文、链接、段落定位、访问日期和内容 hash；
- 未来引入其他作者需新决策或更新本 ADR。

## 后续

用户在评估 Simon 材料质量与可获取性后，决定改为 IELTS 官方 / Cambridge 优先。新策略见 ADR 0003；本文件保留为决策历史。
