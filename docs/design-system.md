# MimicLoop 设计系统

- 状态：Draft，随三个核心页面验证后冻结
- 方向：安静、轻盈、编辑感、阅读舒适

## 句子是主视觉

学习卡首先呈现一句英文。翻译、来源、结构说明和练习支架按需展开，不能用多层卡片或大量同时可见的控制项削弱句子本身。

## 句内标记层级

句内信息分为两层：

1. `chunk`：核心学习目标，使用品牌蓝紫色的浅背景或较明显强调；
2. `gloss`：阅读辅助，使用较轻的同色系文字或点状下划线。

不为每种信息引入一种新颜色。若同一文本同时是 chunk 和 gloss，以 chunk 的视觉样式为主，点击后可以同时展示词块说明和简短释义。

完整原文中的表达另分两层：Core 延续加粗和品牌蓝紫交互提示，并可进入学习详情；Appreciation 不加粗，使用低饱和暖棕点状下划线，只在 hover、键盘焦点或移动端点按时显示短释义。释义浮层直接显示中文含义，不添加“表达欣赏”等重复类型前缀。Appreciation 不能伪装成可点击学习卡，也不能与句子荧光标记竞争视觉优先级。

## 生词释义浮层

点击被标记的生词后，在词语附近打开小型 popover：

```text
adept  adjective
熟练的；擅长的
be adept at doing something
```

约束：

- 默认只显示当前语境相关义项；
- 最多三小行，不展示长词典释义和无关例句；
- 同一时间只打开一个；
- 点击外部或按 Escape 关闭；
- 必须支持键盘聚焦和点击，不能只依赖 hover；
- 浮层不遮住整句，窄屏时允许自动换位；
- 尊重 `prefers-reduced-motion`，只使用轻微淡入或无动画。

## 产品文案语气

界面文案采用克制、具体、功能导向的语气。首页主标题说明产品帮助用户解决什么问题，不重复下方已经可见的今日任务；流程页再直接说明用户正在做什么以及下一步是什么。避免无实际信息的问候、宣传式承诺和模板化口号，例如“下午好”“真的会用”“亲手用出来”；尚未实现的训练能力不得提前写入页面文案。

## Guided Writing 工作台

写作练习优先呈现题目与文章结构，不做成通用聊天窗口或数据仪表盘。桌面端使用左侧题目阅读面、右侧 Essay Map；右侧先展示当前题型真实的论证关系，再给出可调整的推荐起始段落。观点支撑、双方比较、因果应对、影响评价和双问题回答不能画成同一个二元模板。每段只显示职责、目标和一个诊断问题。英文题目继续使用阅读字体，中文分析保持统一正文层级，不用夸张大小字制造结论。尚未开放的逐段写作以锁定阶段显示，入口文案只承诺当前可用的审题与结构能力。

Phase 2.5B 的英文构思不使用聊天气泡。页面采用左侧 Argument Chain、右侧单一 Current Question；已接受的 learner 原句进入对应节点，当前问题保持一个，模型反馈以一条短英文观察呈现。导航与故障说明可保留中文，教学问题、学习者回答与逻辑反馈默认全英文。构思阶段优先判断意思与逻辑，小语法或拼写错误不应阻塞节点推进。

Phase 2.5C 在同一工作台中复用左侧 Argument Chain。语料主交互不得使用平铺卡片墙：learner 每次选择 Main point / Reason / Development / Takeaway 中的一个节点，右侧只处理该节点。语言资产分成两个视觉层级：一个核心句子结构 / Rhetorical Move 负责组织整句；零至三个可搭配 Collocation 只负责局部措辞，不能与核心结构竞争首选。没有适配 Collocation 时不显示辅助区。核心结构明确标记适配原因、学习阶段与迁移边界；提示按中文方向、目标表达、局部骨架、来源参考逐级展开，库内无强匹配时显示 no-fit。节点通过后在左侧显示 learner 的语言实现与提示等级；全部完成后切换为 Paragraph Weaving，不另建作文评分 dashboard。段落反馈只显示同级的 Logic / Language 两栏，每栏最多一个优先问题；minor typo 或局部语法问题使用 `A local surface fix`，不能与逻辑失败使用同一标题。段落正文和反馈继续遵守已确认的可读字号，不用小字堆砌维度、分数或内部枚举。

当某一构思节点需要 IELTS 结构知识时，可在 Current Question 前使用单一左侧细线的 step guide：正文只保留“当前任务”和“暂时不要做什么”两句，字号不低于 13px，不增加嵌套卡片，不给可直接提交的观点、句子或段落。

若 learner 仍不清楚回答形态，step guide 可附一个默认收起的 `Unrelated form examples`。每步最多两条、必须来自其他主题，并注明只观察结构、不复制内容；示例由本地确定性文案提供，不调用模型，也不能针对当前题目供应观点。

Reason 节点在 examples 上方显示独立、常显的 `Logic check · What makes this true?` 小型板块。它使用低饱和蓝紫底色、24px 阅读字体问题标题、三个编号检查项和一行较轻的 IELTS 依据说明；与白底任务说明明显分层，但不能扩张为新的大卡片或抢过 Current Question 的主视觉。

2026-08-27 用户整页复检确认 Guided Writing 首版仍过度使用 9–13px 辅助文字，形成“信息很多但读不清”的 AI 式排版。桌面写作页完成统一可读性调整：普通说明以 15–18px 为主，Argument Chain 的节点标题与 learner 原句分别不低于 18px / 16px，Logic Check 标题与检查项分别为 24px / 15px，技术标签也提升至约 11–13px；页面灰色文字统一加深，并将最大内容宽度放宽至 1280px。不得再通过缩小正文来把所有构思信息强行塞进一屏。

论证链前台使用 `Development`，不向 learner 暴露内部 `mechanism` key；提示应允许因果、原则、比较、问题—回应与条件关系，不能在视觉文案上暗示所有段落都必须写成单一因果模板。

Guided Writing 中 `Position` 属于全文背景，使用独立的淡紫 context block，不与 Body Paragraph 1 的编号步骤混排。主体段左栏只显示 `Main point → Reason → Development → Takeaway`。Development 的右栏可显示一条紧凑三段关系条：learner 的 Reason → `Missing connection` → learner 的 Main point；中间块可以强调，但不得提供当前题目的机制内容。

如果 learner 在上一步已经写出紧邻下一节点的内容，使用独立 `You may already have this` 板块。引用必须是 learner 的精确原文，正文至少 17px，并提供 `Use this part`、`Edit it first`、`Answer separately` 三个同层级明确动作；除 learner 主动确认外不得自动保存或清空输入。

已保存的 Position 与主体段节点在右侧显示 34px 编辑图标按钮，不能让整张节点卡都成为不明确的点击热区。进入回改后，当前节点和所有下游节点分别显示 current / will be rechecked 状态；尚未重新通过更早节点时，更后的编辑按钮必须禁用。原有答案进入输入框供局部修改，不删除历史。

完整论证链复检只使用现有 feedback 区和 Argument Chain，不新增总结仪表盘。需要回改时显示一条短英文诊断，当前节点标为修改中，后续已有节点标为待复检并保留 learner 原文；只有整链通过后才显示完成状态。

## 品牌使用

用户提供的透明 PNG 是 MimicLoop 主品牌资产。首页使用完整 Logo；全局侧栏从同一资产中以裁切视窗显示机器人标志，使所有主要页面保留一致品牌识别。考试定位使用普通文字 `IELTS Academic · Writing Task 2`，不仿制或嵌入 IELTS 官方 Logo；页面同时说明 MimicLoop 为独立、非官方学习工具。

## 使用导览与演示动画

首次使用导览采用真实 UI 片段驱动的 CSS / DOM 循环动画，不使用低清 GIF 截图。导览沿用暖灰阅读面、蓝紫主色、Core 加粗与 Appreciation 暖棕点线，不另造游戏化配色。

- 对话框保持一个主要教学目标，左侧说明、右侧演示；单页循环控制在约 12 秒；
- 光标、悬浮提示与点击波纹必须锚定到被演示的具体词组，禁止依赖演示容器百分比定位，以免换行或缩放后漂移；
- 循环中的相邻教学阶段必须直接交接，不能留下只有用户真实鼠标、没有演示反馈的空档；光标移动到目标前不得提前显形；
- 始终提供暂停、重新播放、右上角单一关闭入口和 Escape；点击遮罩也可关闭，关闭后恢复正文滚动；
- `prefers-reduced-motion` 下移除光标与循环弹层，改为静态说明；
- 窄屏重新排列文案和演示区，不把桌面界面等比缩小，也不能产生横向滚动；
- 写作导览只提供入口级概览，不在导览中复刻复杂的 Guided Writing 流程；可以说明用户可选择题库题目或导入自己的英文 IELTS Task 2 题目，但不得承诺自动代写、Band 评分，也不得把未经 learner 确认的题型与主题判断表现为可信结论；
- 六页使用导览依次覆盖首页入口、原文标记、句子学习、Recall → Use 与 DeepSeek 反馈、搜索定位和写作练习；第 4 页的 AI 反馈必须沿用真实 Use 页的 provider、通过/修改语义和回退边界，不得模拟 Band 评分、自动改写或由模型直接决定掌握状态；页脚必须同时提供顺序翻页与六页直接跳转，末页使用“完成导览”，不能让用户靠关闭按钮结束流程；
- 六页导览已完成，但当前仍不自动强制弹出，也不保存“已看过”状态；只通过首页入口主动打开。
